# //swalter | labs

Responsive bilingual static website for //swalter | labs, with an overview of its .NET libraries, repository migration, and legal notices. The initial language follows browser preferences (German fallback); the header switch lets visitors change languages. The site defaults to dark mode and remembers the selected theme.

Open `index.html` in a browser to preview the site. The page uses the brand icons in `img/` and its styles are in `css/style.css`.
